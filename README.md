# 🎨 Khavaji AutoPaint — WPlace Auto Painter

**Автоматический бот для WPlace на JavaScript, работающий через Tampermonkey.**

Khavaji AutoPaint предназначен для автоматической закраски изображений на [WPlace](https://wplace.live/) по шаблонам `.wplace`.

Бот анализирует изображение и карту, сравнивает цвета пикселей и пытается закрашивать только те участки, где цвет отсутствует или не соответствует шаблону.

**Не требуется скачивать отдельную программу, запускать Python, открывать терминал или устанавливать дополнительное ПО, кроме браузера и Tampermonkey.**

После запуска бот выполняет обработку самостоятельно в открытой вкладке WPlace.

> ⚠️ **Экспериментальная версия.** Автоматическая отправка пикселей в текущей версии может блокироваться защитой Cloudflare с ошибкой HTTP 403. Полностью работоспособная автозакраска пока не подтверждена.

## ✨ Возможности

- 🎨 **Auto Paint** — автоматическая обработка изображения по шаблону.
- 📂 **Импорт `.wplace`** — загрузка шаблонов с координатами.
- 🔍 **Smart Repair** — поиск отсутствующих и неправильно закрашенных пикселей.
- ✅ **Пропуск правильных пикселей** — если нужный цвет уже присутствует, повторная закраска не производится.
- 📐 **Строгий порядок** — рисование сверху вниз, слева направо.
- ⚡ **Мониторинг зарядов** — отображение доступных зарядов с периодическим обновлением.
- 🔄 **Auto Resume** — ожидание выбранного количества зарядов и автоматическое продолжение работы.
- ⏱️ **Настройка скорости** — пауза между запросами от 300 до 30 000 мс.
- 📦 **Размер пакета** — от 1 до 100 пикселей за запрос (сервер может устанавливать дополнительные ограничения).
- 📊 **Прогресс** — количество совпадающих, оставшихся и подтверждённых пикселей.
- 🏅 **Статистика аккаунта** — уровень, прогресс уровня, валюта Droplets и количество нарисованных пикселей, если соответствующие сведения доступны через API.
- 📍 **Последний пиксель** — кнопка перехода к последнему подтверждённому пикселю.
- 📝 **Журнал действий** — отображение операций, ожидания и ошибок.
- 💾 **Сохранение настроек** — восстановление шаблона и параметров после перезагрузки страницы.

## 📥 Установка

### Шаг 1. Установите Tampermonkey

Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для своего браузера.

Для некоторых браузеров необходимо дополнительно разрешить выполнение пользовательских скриптов в настройках расширения.

### Шаг 2. Установите скрипт

1. Откройте Tampermonkey.
2. Перейдите в Dashboard (Панель управления).
3. Нажмите **Create a new script**.
4. Удалите стандартный код.
5. Откройте файл `WPlace_Khavaji_AutoPaint_xxx` из этого репозитория.
6. Скопируйте его содержимое в редактор Tampermonkey.
7. Сохраните через `Ctrl + S`.
8. Убедитесь, что скрипт включён.

### Шаг 3. Откройте WPlace

1. Перейдите на https://wplace.live/.
2. Авторизуйтесь в своём аккаунте.
3. Обновите страницу.
4. Дождитесь появления панели **Khavaji AutoPaint**.

Бот запускается непосредственно в браузере. Дополнительный лаунчер или отдельная программа не нужны.

## 🖼️ Как создать файл `.wplace`

Формат `.wplace` содержит изображение и информацию о его положении на карте.

**Способ через встроенные инструменты WPlace:**

1. Откройте https://wplace.live/.
2. Авторизуйтесь.
3. Перейдите в раздел **Overlays** (Шаблоны).
4. Создайте новый шаблон или загрузите изображение.
5. При необходимости преобразуйте изображение в пиксель-арт и выберите цвета палитры WPlace.
6. Укажите место расположения изображения на карте.
7. Проверьте правильность размера, цветов и координат.
8. Используйте функцию **Export .wplace**.
9. Сохраните файл на компьютере.

После экспорта получится файл с расширением `.wplace`, который можно загрузить в Khavaji AutoPaint.

Подробное руководство: [WPlace — руководство по оверлеям](https://wplace.live/ru/guides/overlays).

**Важно:** текущий скрипт поддерживает вариант `.wplace`, содержащий PNG-изображение в `image.dataUrl` и географические границы в `bounds`. Совместимость с другими вариантами формата не гарантируется.

## 🚀 Как использовать бота

1. Откройте WPlace с включённым Tampermonkey.
2. В панели бота нажмите **«Загрузить .wplace»**.
3. Выберите созданный файл.
4. Нажмите **«Проверить»**, чтобы сравнить шаблон с картой.
5. Укажите настройки скорости, размера пакета и порога ожидания зарядов.
6. Нажмите **«Старт»**.

После запуска скрипт самостоятельно проходит по шаблону, определяет несовпадающие пиксели и пытается отправлять запросы закраски.

**Не нужно вручную переходить к каждому пикселю, открывать координаты или выбирать цвета.**

Для работы необходима открытая вкладка WPlace с активным подключением к интернету. Не закрывайте браузер во время выполнения. Некоторые браузеры могут замедлять выполнение фоновых вкладок.

## ⚡ Автоматическое ожидание зарядов

В панели можно указать порог накопления зарядов.

**Пример:**

- Порог ожидания: `50`
- Доступные заряды: `0`
- Состояние: `Ожидание зарядов`

Когда количество зарядов достигнет установленного порога, скрипт попытается продолжить работу.

Перед продолжением выполняется повторное сравнение шаблона с картой. Пиксели, которые уже имеют нужный цвет, пропускаются.

Если сервер возвращает ошибку Cloudflare, бот останавливает закраску: такая ошибка не считается отсутствием зарядов.

## 📊 Статистика

Панель может отображать:

- Текущий уровень аккаунта.
- Оставшееся количество пикселей до следующего уровня.
- Прогресс уровня в процентах.
- Баланс Droplets.
- Общее количество нарисованных пикселей.
- Текущие и максимальные заряды.
- Прогресс выполнения шаблона.
- Количество запросов и подтверждённых закрасок.

Некоторые значения зависят от доступности данных API. Расчёт прогресса уровня может быть приблизительным.
